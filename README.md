# 我的第一个 GitHub 项目

这是一个给零基础学习者准备的迷你网页，用来练习完整流程：

1. 在电脑上创建文件。
2. 用 Git 保存一个版本（commit）。
3. 在 GitHub 创建仓库。
4. 把电脑上的版本上传到 GitHub（push）。
5. 建立分支，修改内容，再发起 Pull Request。

## 文件是什么

- `index.html`：网页本身，双击即可在浏览器打开。
- `README.md`：项目说明，GitHub 会自动把它显示在仓库首页。

## 最重要的四个概念

- **项目文件夹**：作品在你电脑上的实际位置。
- **Git**：电脑里的“版本存档机”，可以记录每次改动。
- **GitHub 仓库**：放在网上的项目副本，便于备份、分享和协作。
- **Codex/GPT**：根据你的自然语言要求读取、修改、检查这些文件，并在你授权后操作 GitHub。

## 第一次练习

打开 `index.html`，点击按钮。之后可以让 Codex 把标题改成你喜欢的话，再观察新旧版本的差别。
